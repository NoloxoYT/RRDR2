Quick start

From nothing to a working Rust mod in the game.

1. Requirements

  • 64-bit Red Dead Redemption 2, single-player.
  • ScriptHookRDR2 and its ASI loader dinput8.dll in the game folder.
  • Rust stable, .NET SDK, and LLVM (clang-cl, lld-link).
  • On Linux, cross-compiling needs rustup target add x86_64-pc-windows-msvc and cargo install cargo-xwin --locked.

2. Get the source and the tool

git clone https://github.com/NoloxoYT/RRDR2.git
cd RRDR2
cargo install --path build_tools --locked

The tool installs as rrdr in ~/.cargo/bin.

3. Build and install

rrdr

It runs the tests, builds every mod crate, compiles the loader, packages everything in dist/RRDR/ and asks where your game is.

Anything the prompt would ask can be passed up front:

rrdr --loader asi --game-dir "C:/Games/Red Dead Redemption 2" --yes
rrdr --no-install          # build only
rrdr --root ~/RRDR2       # from another directory

4. Write a mod

Create a crate under rust/crates/, add it to the workspace, and make it a cdylib:

[package]
name = "my-rdr2-mod"
version = "0.1.0"
edition = "2021"

[lib]
name = "MyModCore"
crate-type = ["cdylib", "rlib"]

[dependencies]
rrdr-bridge = { path = "../rrdr-bridge" }
rrdr-game = { path = "../rrdr-game" }
rrdr-natives = { path = "../rrdr-natives" }

Implement Mod and call export_mod!:

use rrdr_bridge::{export_mod, GameApi, LogLevel, Mod};
use std::path::Path;

struct MyMod;

impl Mod for MyMod {
    fn init(api: &mut dyn GameApi, _config: Option<&Path>) -> Result<Self, String> {
        api.log(LogLevel::Info, "MyMod loaded");
        Ok(Self)
    }

    fn tick(&mut self, api: &mut dyn GameApi, _dt: f32) {
        let Some(player) = rrdr_game::Player::local(api) else { return };
        if let Some(ped) = player.ped_checked(api) {
            if ped.health(api) < 50 {
                ped.set_health(api, 50);
            }
        }
    }
}

export_mod!(MyMod);

Run rrdr --no-install, then copy dist/RRDR/scripts/Rscripts/MyModCore.dll into <RDR2>/scripts/Rscripts/. The loader picks it up on the next launch.

Every crate under rust/crates/ whose Cargo.toml contains cdylib is built and packaged automatically. Add your crate to the workspace members and it shows up in the next rrdr run.

5. Check the log

The native loader writes <RDR2>/scripts/Rscripts/RRDR.asi.log. A healthy start looks like:

Loading MyModCore.dll
  init ok
Started 3 cores

No file at all means ScriptHookRDR2 or the loader is missing. Details in the reference.
