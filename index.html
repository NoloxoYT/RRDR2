rrdr_natives

Rust bindings for the Red Dead Redemption 2 native API

Typed bindings for the RDR2 natives RRDR wraps, generated from lib/NativeDecl.cs (ScriptHookRDR2DotNet V2). 7501 functions across 86 native namespaces, 7128 unique hashes. Every call goes through GameApi, so it works in game and in the offline simulator.

Search by name or by description - press / and start typing, e.g. nearest ped, set entity health, bleeding. Hashes work too (0x82368787EA73C0F7).

skipped 2 variadic natives not representable in the bridge ABI: DATABINDING::_DATABINDING_WRITE_DATA_SCRIPT_VARIABLES, MISC::VAR_STRING.
